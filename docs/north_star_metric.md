# North Star Metric: 실증 가능한 대장주/대박주 족집게 로직

## 1. 프로젝트의 유일한 최상위 목표

`Leader_Lab`의 모든 구현 목표는 다음 하나로 수렴한다.

> 장중 실제 최고수익률 상위 대장주/대박주를 사전에 높은 순위로 선별하는 실증 가능한 로직을 만든다.

단순히 데이터 수집, UI, 1분봉 캐시, 지표 계산, 백테스트 화면을 만드는 것이 목적이 아니다.

모든 기능은 다음 성과를 올리기 위한 수단이다.

```text
현재 수준:
Score Top10 중 실제 대장주/대박주 적중 약 2개 / 10개

목표 수준:
Score Top10 중 실제 대장주/대박주 적중 7개 / 10개 이상
```

즉, 10개 중 2개는 현재 최악/기준 상태이며, 10개 중 7개 이상이 실전 채택의 핵심 목표다.

---

## 2. 평가 기준 정의

### 2.1 대장주/대박주 정의

1차 정의:

- 일자별 1516 포착 종목 중 `max_ret_in_period` 상위 종목
- `max_ret_in_period >= 10%` 종목

2차 정의:

- 실제 최고수익률 Top5 / Top10
- 당일 주도 테마/섹터 내 수익률 상위
- 거래대금과 상승 지속성이 동반된 종목

### 2.2 적중률 정의

가장 중요한 지표는 다음이다.

```text
Hit@10 = Score Top10 ∩ Actual MaxRet Top10 개수
```

예:

```text
Score Top10 중 실제 MaxRet Top10 종목이 7개 포함
→ Hit@10 = 7 / 10 = 70%
```

보조 지표:

- Hit@5
- Top1Capture
- ScoreTop5 Label10Rate
- NDCG@5
- NDCG@10
- Lift@5
- Lift@10

## 3. 성공 기준

### 3.1 현재 기준선

현재 상태는 다음 수준으로 간주한다.

```text
Score Top10 중 실제 대장주/대박주 약 2개 적중
```

이것은 기준선이며, 실전 의미가 낮다.

### 3.2 1차 통과 기준

```text
Score Top10 중 실제 Top10 평균 5개 이상 적중
Score Top5 중 실제 Top5 평균 2.5개 이상 적중
Score Top5의 label_10 비율 35% 이상
랜덤 대비 Lift@5 2배 이상
```

### 3.3 강력 통과 기준

```text
Score Top10 중 실제 Top10 평균 7개 이상 적중
Score Top5 중 실제 Top5 평균 3개 이상 적중
Score Top5의 label_10 비율 45% 이상
랜덤 대비 Lift@5 3배 이상
```

### 3.4 실전 채택 기준

```text
Train / Validation / Test 모두에서 성능 유지
Test 구간 성능이 Train 구간의 70% 이상 유지
특정 날짜/종목 의존도 낮음
실시간 계산 가능
로직 설명 가능
```

## 4. 모든 기능의 종속 관계

다음 기능들은 모두 North Star Metric을 위한 하위 수단이다.

### 데이터 수집

- 1516 성과검증 결과
- 일봉 데이터
- 1분봉 데이터
- 3/5/15분봉 재구성 데이터
- 섹터/뉴스/프로그램 순매수 데이터

목적:

```text
대장주/대박주 적중률을 높일 feature 확보
```

### UI

목적:

```text
데이터 누락 없이 매일 갱신하고, 적중률 개선 여부를 즉시 확인
```

### Custom Screener

목적:

```text
키움 조건검색식으로 표현하기 어려운 고성능 필터를 조합하여 Score Top10의 대장주 적중률을 높임
```

### Backtest / Simulation

목적:

```text
선별 로직의 실전 매매 가능성을 검증
```

## 5. 금지되는 구현 방향

다음은 프로젝트 목표에서 벗어난다.

1. 단순히 예쁜 UI만 만드는 것
2. 데이터만 많이 저장하고 적중률을 검증하지 않는 것
3. 평균수익률만 보고 TopK 적중률을 보지 않는 것
4. 과거 전체기간에만 맞는 과최적화 로직
5. 10개 중 2~3개 적중 수준을 개선 없이 유지하는 것
6. 실제 매매 가능한 시간에 계산할 수 없는 과도한 로직
7. 설명할 수 없는 블랙박스 점수

## 7. 핵심 문장

`Leader_Lab`의 모든 코드는 다음 문장을 검증하기 위해 존재한다.

> 우리가 만든 점수 Top10을 샀을 때, 그 안에 실제 대장주/대박주가 7개 이상 들어오는가?

이 질문에 숫자로 답하지 못하는 기능은 우선순위가 낮다.
